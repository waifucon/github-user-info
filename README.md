# GitHub User Info API Integration

A simple command-line Python utility that integrates with the GitHub REST API to fetch and display public user statistics and account creation timestamps.

## Features

* **GitHub API Integration:** Queries the public `/users/{username}` endpoint.
* **Data Retrieval:** Fetches public repository counts and original registration timestamps.

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/waifucon/github-user-info.git
   ```
2. Run the script:
   ```bash
   python3 github-user-info.py
   ```
3. Enter any valid GitHub username.
